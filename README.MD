# Задание 3 (дедлайн 16.04.2025)
## Разработка собственного Spring Boot стартера

1. Создать Spring Boot стартер, который будет добавлять функциональность логирования API-запросов и ответов в приложении.
Методы, которые необходимо логировать, явно определяет разработчик.
2. Логирование реализовать через _Aspect_.
3. Добавить возможность настройки логирования через параметры в _application.yml_.
4. Разрешить пользователям включать или отключать логирование, а также выбирать уровень логов (_info_, _debug_, _warn_, _error_). Пользователь указывает уровень логирования для всех выводимых сообщений.
